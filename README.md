# ComicCraft-AI-Comic-Story-Creator-using-Gemini-Models
ComicCraft: AI Comic Story Creator using Gemini Models
​ComicCraft is an innovative AI-driven application designed to transform text ideas into structured comic stories, character dialogues, and visual scene descriptions using Google Gemini AI models. It streamlines the creative storytelling process by generating panel-by-panel comic scripts complete with character details, emotional tone, and artistic layout suggestions.
​📌 Project Overview
​The core codebase features a modular Python architecture that integrates the google-generativeai SDK. It converts user text prompts into structured visual narratives ready for comic artists or text-to-image AI generators.
​✨ Key Features
​Panel-by-Panel Script Generation: Automatically breaks down stories into structured comic panels with shot types (Close-up, Wide shot, etc.) and visual cues.
​Dynamic Character & Dialogue Creation: Generates engaging character interactions, distinct voices, and sound effects (onomatopoeia).
​AI Image Prompt Generator: Converts visual descriptions into optimized prompts ready for AI image generators (Midjourney, DALL-E 3, Stable Diffusion).
​Structured Parsing & Export: Processes Gemini API outputs into structured formats (JSON/Markdown) for easy integration or downloading.
​Custom Tone & Style Controls: Allows users to define genres (Sci-Fi, Manga, Superhero, Fantasy) and visual aesthetic styles.
​Robust Error & Rate Handling: Implements clean handling for API rate limits and safety settings.
​🛠️ Tech Stack
​Language: Python 3.10+
​AI Engine: Google Gemini API (google-generativeai)
​User Interface: Streamlit / Flask
​Environment Management: python-dotenv
